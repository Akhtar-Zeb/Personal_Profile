# Akhtar Zeb Portfolio Website

## Files
- `index.html` — page content and sections
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation, active nav state, and current year

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code.
3. For VS Code, you can use the Live Server extension.

## Personalize before publishing
- Replace the LinkedIn URL in the contact section with your own profile.
- Add your email address or a contact form if you want visitors to email you.
- Add links to live demos and certificate verification pages.
- Check project descriptions and certificate dates for accuracy.
- Add your own portrait in place of the initials illustration if desired.

## Publish with GitHub Pages
Upload the three website files to the root of your GitHub repository, commit and push them, then open repository Settings → Pages and select the `main` branch and `/ (root)` folder.
